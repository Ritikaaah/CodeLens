# CodeLens — AI-Powered Code Reviewer

CodeLens is an AI-powered code review application designed to help developers identify potential bugs, security vulnerabilities, and code quality issues.

The project combines traditional static analysis techniques with AI-powered explanations and improvement suggestions to make code reviews more informative and accessible.

## Features

- Code submission and analysis
- Bug and code quality detection
- Security vulnerability identification
- AI-powered explanations
- Suggestions for improved code
- Structured code review reports

## Technology Stack

- Python
- FastAPI
- HTML, CSS and JavaScript
- Ruff
- Bandit
- Large Language Models (LLMs)

## Project Status

Currently under development.

## Vision

To build an accessible code review assistant that not only identifies problems but also helps developers understand and improve their code.
